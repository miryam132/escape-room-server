# Escape Room Server — שרת חדרי בריחה

שרת Node.js + Express + TypeScript לחדרי בריחה בתוך תמונה אחת. זהו שרת API, לא אתר React. התחל ב־[START-HERE.md](START-HERE.md).

## מה כלול

- הרשמה והתחברות ב־JWT; הרשאות ADMIN ו־PLAYER.
- ניהול חדרים ונקודות לחיצות; שני סוגים בלבד: INFO ו־PUZZLE.
- תלות בחידה אחת, רמז אחד, תוכן לאחר פתרון וחידת סיום.
- שמירת התקדמות לכל שחקן וחדר, חידוש משחק ואיפוס אישי.
- PostgreSQL באמצעות Prisma, קובץ Migration ונתוני הדגמה בעברית.
- העלאת תמונה ל־Supabase Storage, לאחר פענוח וקידוד מחדש ל־WebP.
- Swagger ב־`/api-docs` ו־OpenAPI ב־`/openapi.json`.
- בדיקות אוטומטיות והכנה לפריסה ב־Render. אין שירות AI או API בתשלום שנדרש להפעלה.

## התחלה מקוצרת

נדרש Node.js 24 ומסד PostgreSQL. מסד Supabase יכול לשמש גם כשהשרת רץ במחשב שלך. אין צורך ב־Docker.

```powershell
npm.cmd ci
Copy-Item .env.example .env
```

מלא את המשתנים לפי START-HERE, ואז:

```powershell
npm.cmd run db:generate
npm.cmd run db:migrate
npm.cmd run admin:create
npm.cmd run db:seed
npm.cmd run dev
```

כתובת מקומית: http://localhost:3000/api-docs

## גבולות הגרסה

אין טיימר, ניקוד, מלאי חפצים, גרירה, טיוטות, שחזור סיסמה, אימות אימייל או Refresh Token. Token תקף לשעתיים; אחריהן מתחברים שוב. Logout מתבצע במחיקת ה־Token בצד הלקוח. אין ביטול מיידי של Token בודד.

לכל חדר חידת סיום אחת. כל שאר החידות חובה; חפצי מידע אינם נספרים. חידת הסיום נשארת נעולה עד שכל היתר נפתרו גם אם לא הוגדרה לה תלות מפורשת.

כל שינוי בנקודה לחיצה מאפס את ההתקדמות של כולם בחדר. גם שינוי כתובת התמונה מאפס. שם, תיאור, קטגוריה וקושי אינם מאפסים. יש להציג אזהרה לפני שמירת עריכות אלה ב־React.

תמונות החדרים ציבוריות באמצעות כתובת האחסון; תשובות וחומר שנחשף רק אחרי פתרון נמצאים ב־DB ומוגנים דרך השרת. אל תטמיע תשובות סודיות בשם הקובץ או בתמונת הרקע אם אינך רוצה שיראו אותן.

מחיקת חדר מוחקת את החידות וההתקדמות, אך אינה מוחקת אוטומטית את הקובץ באחסון. גם העלאה שלא נשמרה בחדר נשארת שם. בגרסה הקטנה מנקים קבצים לא בשימוש ידנית ב־Storage; לא מוחקים קובץ המשמש חדר אחר.

## בדיקות

ברירת המחדל של `npm test` יוצרת מסד בדיקה זמני על דיסק באמצעות PGlite, גרסת WASM של PostgreSQL, ומפעילה את המיגרציות ואת Prisma דרך פרוטוקול PostgreSQL. זהו כלי לבדיקות בלבד; השרת הרגיל דורש PostgreSQL חיצוני ואינו משתמש במאגר בזיכרון.

אפשר להריץ את אותן בדיקות מול PostgreSQL רגיל באמצעות `TEST_DATABASE_URL`, בתנאי שמדובר במסד בדיקה ייעודי עם `schema=escape_room_test`. הבדיקות מוחקות את כל נתוני הסכמה הזאת. אין להשתמש במסד העבודה או בענן החי. פרטי ההרצה והמגבלות ב־`docs/TEST-REPORT.md`.
