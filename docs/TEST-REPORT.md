## סביבת הבדיקה ומגבלות

הבדיקות המקומיות משתמשות ב־PGlite על דיסק זמני דרך פרוטוקול PostgreSQL וב־Prisma האמיתי. זהו PostgreSQL ב־WASM לצורכי בדיקה; לא נבדק כאן שרת PostgreSQL רגיל או מסד Supabase חי. סביבת הבדיקה אינה מחליפה את מסד PostgreSQL הנדרש בהפעלת המוצר.

בקשות האחסון ל־Supabase הוחלפו ב־mock בבדיקות. פענוח התמונות עצמו אמיתי. העלאה לחשבון Supabase שלך, נגישות דרך נטפרי, חיבור הקליינט שלך ופריסה ב־Render עדיין דורשים בדיקה לאחר ההגדרה.

לא בוצעה פריסה בענן, לא נוצרו חשבונות חיצוניים ולא הוגדרו סודות אמיתיים. Render נבדק מבנית בלבד, לא דרך CLI מאומת או פריסה חיה.
